Five-minute system tour

Context is a plane,
not prompt plumbing.

Sources publish once. Agentic workflows retrieve one way—with authorization before ranking, stable citations, explicit freshness, and memory that cannot impersonate source truth.

One governed path from change to context
Source Ingestion Governance Workflow

Authorize before relevance

OPA returns immutable tenant, corpus, classification, field, namespace, and limit constraints. User filters may only narrow them.

Derived, replayable state

Stable IDs, monotonic source versions, content hashes, tombstones, and post-write checkpoints make at-least-once CDC safe.

Trust stays visible

Institutional content and agent memory live in separate index families. Proposed memory never silently becomes source truth.

A request in six moves

Verify identity and workloadAuthenticate the bearer token; verify the timestamped HMAC over canonical workload headers.
Ask policy, then freeze constraintsAny OPA timeout, malformed answer, or uncertainty fails closed before search.
Retrieve both waysBM25 protects exact SKUs and policy IDs; vectors add paraphrases and conceptual matches.
Fuse deterministicallyReciprocal-rank fusion k=60 preserves component ranks; the v1 reranker is intentionally a no-op.
Budget, validate, and citeTrust, freshness, token, candidate, and result limits produce compact context with stable source versions.
Emit evidenceConnected traces, Prometheus metrics, and privacy-safe audit records make relevance and security inspectable.
